Elements

Elements are the building blocks of HTML. They are represented by tags, which can be nested inside one another to create a hierarchy of content. Each element can have attributes that provide additional information about the element.

Attributes

Attributes are special properties that can be added to HTML elements to provide additional information. They are always specified in the opening tag of an element and consist of a name and a value, separated by an equals sign. For example, the src attribute in an <img> tag specifies the source of the image file.

Style

The style attribute is used to apply CSS styles directly to an HTML element. It can be used to change the appearance of an element, such as its color, font size, and background color. For example, <p style="color: red;">This text is red.</p> will display the text in red color.

Script

The script tag is used to include JavaScript code in an HTML document. It can be placed in the <head> or <body> section of the document. For example, <script>alert('Hello, world!');</script> will display an alert box with the message "Hello, world!" when the page is loaded.
